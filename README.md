## What I found interesting 


I found interesting that one software component can create risks across completely different industries. I think it's incredibly impressive to think about the larger issue at hand, rather than focusing on just ATMs because the easiest way to think about problems is through such a narrow lens. This flaw in ATMs can affect healthcare, manufacturing, government systems that use this software, and more, and as a double major in media and communications, I see the value in realizing how interconnected the world is. It's important to realize that things can have consequences that you would have never considered, especially when creating technology!
